Notes on direction a

  • structureOne table instead of four stacked cards. Today each group is its own card with its own repeated header row, so the columns never line up and the page reads as a wall. Here the groups are section rows inside a single table — one set of column headers, everything aligned top to bottom.
  • newGroup subtotals. The group row carries allocated / spent / left for the whole group. That number does not exist anywhere in the app today, and it is the one you scan for.
  • newA pace meter per row replaces mental arithmetic across three mono columns. The status badge becomes redundant, so the column is gone — colour on the meter carries it.
  • newAllocated is edited in place. Click the number, type, press enter. The modal and the per-row "Allocate" button both disappear, which is what frees the width for the meter. Try it — the cells are editable in this mock.
  • chromeThe goal input becomes a tile. It occupies prime space today for something you set once a month; here it is a stat tile you click to edit, consistent with the other three.
  • chromeThe bulk-actions card is gone. "Copy from august" sits in the table toolbar, "Auto-allocate" is the header primary, and "Reset this month" moves into the overflow menu — it should not sit one pixel away from a routine action in matching button size.
  • newFilter chips for "over budget" and "unallocated" make a 17-row table navigable without scrolling for red.
  • fixRow click still opens that category's transactions, but the cursor and hover row tint now advertise it.
