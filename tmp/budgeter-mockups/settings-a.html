Help

What each page does
  • Dashboard — the month at a glance: spent, pace against your goal, what needs attention.
  • Budget — allocate a dollar amount per category and watch it against actuals.
  • All — the full ledger. Edit, split, flag recurring, bulk-categorize.
  • Uncategorized — anything the keyword rules missed.
  • Settings — this page.
Categories and auto-categorization

Categories live inside groups such as bills, everyday and discretionary. Each category holds a list of keywords, and on import any transaction whose payee contains a keyword is categorized automatically.

  • Keywords are case-insensitive and match anywhere in the payee.
  • If several categories match, the first one wins, in group order.
  • Fix misses from the uncategorized page, then add the keyword here so it matches next time.
Importing transactions

Drop a CSV from your bank onto the import button. The importer parses it, deduplicates against what is already stored, and runs auto-categorization on whatever is new.

Required columns: date, payee or description, and amount. Quoted and tab-separated variants are handled.

Splits and recurring transactions

Split — one transaction divided across several categories, for example a Costco run that is part groceries and part household. The parts sum to the original.

Recurring split — apply the same split to every future transaction from that payee.

Split payment — mark a transaction as a payment toward another one, so a card payment does not double-count against the original charge.

Using the Claude connector

Budgeter exposes six tools over MCP. Add it once in claude.ai under settings, connectors, then ask questions in plain language — "what did I spend on groceries in august", "categorize the uncategorized Amex charges as gas".

Authentication is OAuth through base, so there is no key to paste. The fallback key above exists only for scripted access.

Access and security

Budgeter is reachable at budgeter.joenguyen.ca through a Cloudflare tunnel. Browser routes sit behind Cloudflare Access on your email. API routes bypass Access and carry their own auth headers plus rate limiting at 120 requests per minute per IP.

Danger zone

Deletes every transaction, split and import record. Categories and allocations are kept. This cannot be undone.
