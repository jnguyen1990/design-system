Help

What each page does
  • Dashboard — the month at a glance: spent, pace against your goal, what needs attention.
  • Budget — allocate a dollar amount per category and watch it against actuals.
  • All — the full ledger. Edit, split, flag recurring, bulk-categorize.
  • Uncategorized — anything the keyword rules missed.
Categories and auto-categorization

Categories live inside groups such as bills, everyday and discretionary. On import, any transaction whose payee contains one of a category's keywords is categorized automatically.

  • Keywords are case-insensitive and match anywhere in the payee.
  • If several categories match, the first one wins, in group order.
Importing transactions

Drop a CSV from your bank onto the import button. The importer parses it, deduplicates against what is already stored, and runs auto-categorization on whatever is new. Required columns: date, payee or description, and amount.

Splits and recurring transactions

Split — one transaction divided across several categories. Recurring split — apply the same split to every future transaction from that payee. Split payment — mark a transaction as a payment toward another, so a card payment does not double-count.

Access and security

Budgeter is reachable at budgeter.joenguyen.ca through a Cloudflare tunnel. Browser routes sit behind Cloudflare Access on your email. API routes bypass Access and carry their own auth headers plus rate limiting at 120 requests per minute per IP.

Deletes every transaction, split and import record. Categories and allocations are kept. This cannot be undone.

Notes on direction b

  • structureOne section visible at a time. Settings today is a 520-line scroll of eight cards; here it is a 190px section list and a single pane. The page is never taller than its tallest section.
  • structureThe danger zone is a section you have to choose. Right now it sits at the bottom of the same scroll as the README editor, which means you pass it every time you use the page.
  • newAn "about this app" pane gives version, host, database size, deployed commit and design-system version somewhere to live. That information is currently buried in the help text where it goes stale — which is exactly what happened to the MCP card.
  • sameEvery content fix from direction a applies here too: corrected connector card, DS form classes, sentence case, hover row actions, honest danger-zone copy.
  • riskTrade-off: you cannot ⌘F the whole page any more, and it is more machinery than a single-user app may need. Direction a is closer to how base and fitness settings already look, so it keeps the constellation consistent; this one is nicer to use but makes budgeter the odd app out unless the pattern is adopted everywhere.
